# Airbnb SQL Datamart

Airbnb-style relational database and SQL datamart built for the IU International University course DLBDSPBDM01 (Build a Datamart in SQL).

## Contents

- `airbnb_create.sql` - schema/table definitions
- `airbnb_insert.sql` - sample data inserts
- `airbnb_db_final.sql` - final full database dump (schema + data)
- `join_1_testQuery.sql`, `join_2_testQuery.sql` - test queries against the datamart
- `DB_instalation_manual.pdf` - installation/setup instructions

## Setup

Run `airbnb_create.sql` followed by `airbnb_insert.sql` (or use `airbnb_db_final.sql` alone) against a MySQL 8.0 instance. See the installation manual PDF for full instructions.
